이 폴더에 넣을 파일

1) hanshin-logo.png  ← 한신대 로고
   - 배경이 투명한 PNG 를 권장합니다.
   - 높이 100px 이상이면 충분합니다 (화면에는 32px 로 줄여서 표시됩니다).
   - 파일을 넣기 전까지는 상단바에 글자 마크(ES)가 대신 나옵니다.
   - 로고가 원래 흰색이라면 data.js 에서 logoInvert 를 false 로 바꾸세요.

2) hero.jpg  ← 첫 화면 대표 사진 (선택)
   - 가로로 긴 21:9 비율이 잘 맞습니다.
   - data.js 의 SITE.heroImage 에 "assets/images/hero.jpg" 를 적으면 나타납니다.

3) 구성원 사진, 활동 사진
   - 파일 이름은 영문 소문자와 하이픈만 사용하세요 (예: hong-gildong.jpg)
   - 한 장당 500KB 이하로 줄여서 넣으시면 페이지가 빠릅니다.
